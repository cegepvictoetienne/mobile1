# Les conditions de l'App Store

La publication d'une application sur l'App Store n'est pas la seule voie pour rendre disponible une application que vous avez développé pour  iOS. Cependant, ceci demeure le meilleur endroit pour faire connaître vos applications et atteindre potentiellement un nombre impressionnant de personnes.

Sachez que pour publier sur l'App Store, vous devez vous abonner au [Apple Developer Program](https://developer.apple.com/programs/whats-included/). Attendez-vous à débourser 99 USD annuellement pour cet abonnement.

Apple ne permet pas à n'importe quelle application d'être publiée sur son App Store. Il impose des règles assez strictes afin d'assurer un certain niveau de qualité et de sécurité pour les applications que les gens téléchargent.

Il est important de connaître ces règles avant le début du processus de développement afin de mettre de votre côté toutes les chances de voir votre application acceptée sur l'App Store.

Le détail des conditions est disponible [sur le site de Apple](https://developer.apple.com/app-store/review/guidelines/) et peuvent avoir été modifiées depuis que cet article a été rédigé. Aussi, il est de votre devoir d'en prendre connaissance directement sur le site de Apple.

Voici quelques conditions à titre d'exemple :

- l'application doit être exempte de bogues
- l'application ne doit pas présenter de contenu offensant, discriminatoire, pornographique, etc.
- pendant le processus d'installation, l'application ne doit pas télécharger de contenu externe
- l'application ne doit pas être une simple interface pour afficher le contenu d'une application tierce
- etc.
