# Exercice 6 : Rejouer une partie enregistrée

Vous devez poursuivre le développement de votre [jeu de mémoire](jeu-de-memoire.md).

1. Créez des styles personnalisés pour les vues auxquelles vous appliquez plus de deux modifieurs. Vous devrez dorénavant respecter cette consigne dans toutes les applications que vous développerez, sauf si avis contraire.
2. À chaque fois qu'une carte change d'état (face cachée ou visible), votre application doit pouvoir tenir un historique qui indique quelle carte a été modifiée ainsi que son état actuel.
3. Ajoutez une option dans la barre de navigation de votre application. Ce bouton permet de rejouer la partie qui est présentement en mémoire. Suggestion : si vous désirez utiliser un symbole SF, demandez à un outil d'IA de vous suggérer lequel utiliser. L'option ne sera visible que si la partie est terminée.
4. Écrivez le code qui sera exécuté quand l'usager clique sur cette option. Pendant que la partie se rejoue automatiquement, l'usager n'a rien à faire. Assurez-vous qu'il ait le temps de voir ce qui se passe à l'écran.
5. **OPTIONNEL** : faites en sorte qu'il ne soit pas possible de cliquer sur une carte pendant que la partie se rejoue automatiquement.
6. **OPTIONNEL** : une autre option permet de réinitialiser la partie même si elle n'est pas terminée. L'usager devra cliquer sur un bouton de confirmation pour que la réinitialisation ait lieu.
